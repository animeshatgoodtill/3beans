# 3beans.co.uk website

Static site deployed on Vercel from the `main` branch. No build step: Vercel serves the files as they are.

- `index.html` – the whole homepage (HTML + CSS in one file)
- `favicon.svg` – logo mark, also used in the header
- `vercel.json` – clean URLs

## Editing
- Edit the HTML directly, commit, push to `main`. Vercel deploys in about a minute.
- Use a branch for bigger changes: Vercel gives each branch a preview URL.

## Content rules
- Business: fixed-fee bookkeeping, payroll and VAT for UK cafés, coffee shops and restaurants (POS → Xero/QuickBooks).
- Prices must match the business plan (Single £129, Double £219, Triple £349, setup £149).
- Never say where leads come from. Listing POS systems we support is fine.
- No made-up testimonials, client logos, certifications or partner badges. Add them only when real.
- Plain, simple English; UK spelling.
